   # GEN_AI: Conditional GAN Fashion-MNIST

   Proyek kelompok Vibe Coding Generative AI From Scratch.
   Model: Conditional GAN (PyTorch) pada Fashion-MNIST, dibuat lewat
   vibe coding bersama LLM.

   ## Pembagian
   - Axel: Bagian 0-2 (Config, Utils, Generator)
   - Bianka: Bagian 3-4 (Dataset, Classifier pendamping, Generate)
   - Sandra: Bagian 5-7 (Discriminator, Training loop, Evaluasi)
   - Sri: Log interaksi LLM dan laporan

   ## Isi repo
   - cGAN_FashionMNIST.ipynb: notebook utama
   - `cGAN_Dataset_Classifier_Generate.ipynb`: Bagian 3-4 (dataset, classifier pendamping dengan akurasi test 91,47%, dan fungsi `generate`). Memuat notebook utama lewat `%run`.
